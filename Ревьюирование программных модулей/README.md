ИНСТРУКЦИЯ ПО РАЗВЕРТЫВАНИЮ
Для того чтобы развернуть проект, необходимо иметь VSC. 

Скачанную папку с проектом, нужно открыть через VSC: - file - open folder - "название папки с проектом".

Далее нужно установить непосредственно сам python, если его нет: откройте консоль(желательно от имени администратора) и впишите команду "winget install Python.Python.3.11" это не совсем обычная установка питона, т.к. данная команда еще автоматически его настроит в средах разработки.

И самое главное библиотеки благодаря которым код работает: отройте терминал в VSC и впишите команду "python -m pip install PyQt6 Pillow pytest" данная команда установит важные библиотеки для запуска проекта.

Самая главная часть - запуск проекта, просто откройте файл в окружении( в полностью открытой папке с проектом в самом VSC) с названием main.py и нажмите на клавиатуре F5 или кликните мышкой на запуск файла в самом интерфейсе

Если все импортировано, загружено и открыто верно, то проект запустится.
